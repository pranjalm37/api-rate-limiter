How the four algorithms differ

Same traffic pattern, four different rules for deciding what gets through.

Fixed Window

Counts requests in fixed clock-aligned intervals. Cheapest, but a burst can land right at a window boundary and effectively double up.

Sliding Window Log

Stores every request timestamp and checks the trailing window exactly. No boundary burst, but cost grows with request volume.

Sliding Window Counter

Approximates the sliding window using two weighted fixed-window counters. Nearly as accurate as the log, at fixed-window cost.

Token Bucket

Refills tokens continuously and allows short bursts up to capacity while still capping the long-run average rate. What most production APIs use.
